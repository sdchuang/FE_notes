# FE_notes

一个偏“前端刷题 + 原生 JS 实战”的代码仓库：用手写实现来巩固常见数据结构与业务/基础场景。

## 仓库包含什么

### `algorithm/` 常见数据结构与算法

- `数组/`、`栈/`、`链表/`、`字符串/`：对应数据结构相关的题型练习与基础实现
- `动规/`、`回溯/`：动态规划、回溯相关思路与模板
- `树/`：树结构（当前包含 `二叉树.js`）
- `排序.js`：归并/快速/冒泡/插入等基础排序实现

### `编程题/` JS 基础场景与手写实现

目前主要在 `编程题/js基础题/` 下：

- `base.js`：常见基础能力（例如拷贝等）/场景实现
- `js原生api.js`：原生 API 相关手写实现
- `promise.js`：`Promise.all` / `Promise.race` / `Promise.any` 等实现
- `继承.js`：继承/原型相关的实现练习
- `高频.js`：高频考点/常见写法的整理与练习

## 如何使用

仓库内大多数文件是“可读可运行”的手写实现（通常不依赖打包工具）。

- Node 运行：`node path/to/file.js`
- 浏览器运行：把脚本内容粘到 Console/页面脚本中执行（如涉及全局对象/原型扩展）

如果某个文件只用于阅读/推导，也可以直接当作笔记来参考。

## 贡献建议

新增内容时尽量做到：

- 放在对应目录（`algorithm/` 或 `编程题/`）
- 文件名尽量明确（例如数据结构/专题名称）
- 关键实现保持可读性：函数/步骤尽量有简要注释，便于以后复习
